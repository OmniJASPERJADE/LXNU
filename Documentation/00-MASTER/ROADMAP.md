# Roadmap

## 1. Purpose
This document records implementation order, milestone gates, and dependency sequencing for the System-One platform. The roadmap is intentionally document-driven and dependency ordered rather than alphabetical.

## 2. Implementation sequence
1. Architecture and engineering governance
2. LXNU and AMD64 platform
3. Toolchain and SIMD
4. OmniSilicon
5. Omni Performance Libraries
6. OmniRed and OrbionFS
7. OmniSoft and Photon
8. Distribution and validation

## 3. Phase milestones
- Baseline architecture and ownership model
- Hardware and kernel platform definition
- Toolchain and runtime dispatch decisions
- Heterogeneous accelerator qualification
- Storage, services, and coordination architecture
- Userspace integration and desktop implementation
- Release packaging and verification

## 4. Release gates
A release gate exists at each phase when documentation, implementation, and validation evidence must all align before a subsystem can move to the next milestone.
