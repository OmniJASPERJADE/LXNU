# Documentation Directory

This directory is the canonical home for System-One architecture and subsystem specifications. The numbered subsystem documents are organized under `00-MASTER/` through `12-UPSTREAM/`.

The repository also contains an older lower-case `docs/` tree. It remains unchanged as the source of legacy LXNU policies and validation material. The legacy inventory and recommended integration mapping are tracked in [`00-MASTER/LEGACY-DOCUMENTATION-INDEX.md`](00-MASTER/LEGACY-DOCUMENTATION-INDEX.md).

> Migration note: this index records where each legacy document belongs. The legacy source files have not been deleted or altered.
